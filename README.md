# VISIONS Match LP

Landing page for VISIONS Match — AI health coaching via LINE.

## Analytics Setup

1. Visit https://analytics.google.com and create a new GA4 property
2. Copy your Measurement ID (format: G-XXXXXXXXXX)
3. Replace `G-XXXXXXXXXX` in `index.html` with your real ID
4. Commit and push — tracking will begin within 24h
